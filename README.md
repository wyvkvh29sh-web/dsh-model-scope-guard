# dsh-model-scope-guard

DeepSeek Harness Desktop 的“修改范围管控”插件。它让用户按 **厂商 / 模型** 选择需要约束的目标模型，并仅在这些模型处理修改类请求时注入严格的最小变更规则。

## 行为

- 输入框右侧的 `⌖` 按钮打开管控面板。
- 打开面板时自动读取当前配置的厂商/模型；若读取失败，可点击“重新获取”；点击“管控当前模型”即可加入目标列表，并可随时移除。
- 目标列表持久化到 DSH 设置；未选中的模型不会收到该约束。
- 对目标模型，修改、调整、优化、修复等任务要求：
  - 严格以用户明确范围为边界；
  - 不擅自扩展需求、重构无关内容、调整配置或做“顺手优化”；
  - 范围不清时先澄清；
  - 使用最小、局部、可逆的改动；
  - 交付时明确输出“修改内容 / 修改范围 / 未修改部分 / 范围外发现”。

## 安装

该插件仅安装到桌面端 Profile：

```bash
dsh plugin --profile desktop add file:/绝对路径/dsh-model-scope-guard
```

然后完全重启 DeepSeek Harness Desktop。

## 验证

```bash
node --check lib/index.js
node --check lib/client.js
```

在 Desktop 中选择一个模型，打开 `⌖` 面板并添加该模型。随后让它修改一个小范围内容，检查系统提示词与最终输出是否含有范围约束和四段式交付说明。
